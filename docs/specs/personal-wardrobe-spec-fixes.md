## 二、§1.2 校色 —— 整节未实现

| # | spec 位置 | 现状 | 目标行为 |
|---|---|---|---|
| 1 | §1.2 参考物 | 无任何代码 | 灰卡优先、白纸 fallback；两者都检不出 → **跳过自动校色**（不猜白平衡） |
| 2 | §1.2 流程 | 无 | 自动检出参考物区域 → **用户可手改框选范围**（可拖拽改框、可在灰卡/白纸之间切换类型）→ 以框内像素作白平衡基准 → 应用到整图 |
| 3 | §1.2 基准差异 | 无 | 灰卡按**中性灰**（三通道拉平到均值）；白纸按**纯白**（拉到 255） |
| 4 | §1.2 手动白平衡 | 无 | 无参考物的照片：详情页给**色温 / 色调滑块 + 重算** |
| 5 | §1.2 重置 | 无；且**原图没保留**（`process_and_store` 丢弃上传字节，只留三档 JPEG） | 校色可**重置回原图**；原图永远保留 |
| 6 | §1.2「原图」⚠️ **原文未定义** | — | **= 上传后经 EXIF 转正、限长 2400px 的那份工作图**，入库时另存**不可变副本**；上传原始字节不保留。校色/抠图/旋转都不得覆盖它 |
| 7 | §1.2 增益安全 ⚠️ **原文未定义** | — | 参考区极暗/极亮时白平衡增益须**有界**，输出钳在 [0,255]；不得把整图冲成纯白或压成纯黑 |
| 7a | §1.2 与旋转的坐标一致性 ⚠️ **原文未定义**（2026-10-12 端到端发现） | — | **校色前原图副本必须与工作图保持同一朝向**：旋转时同步旋转该副本（同路径原地写）。否则检出框（工作图坐标）与应用裁切（原图坐标）不在同一空间，旋转后白平衡会从错误区域计算；且「重置回原图」会连用户的旋转意图一起撤销。「不可变」的本意是**校色不得用其产物覆盖它**，不禁止几何同步 |
